# 校园访客审批平台

面向“河北省科技工程学校”的校园访客审批系统。系统支持访客申请、二维码查询、部门负责人审批、保卫处审批、账号与部门管理、门卫大屏核验等功能，数据库使用本地 MySQL。

## 功能概览

- 访客免登录申请：申请人通过网址或二维码进入申请页，填写部门、申请人、访客、车牌、事由和到访时间。
- 部门负责人审批：申请人选择“需要部门负责人审批”时，必须选择该部门具有审批权限的负责人。
- 保卫处审批：无需部门审批的申请直接进入保卫处；部门审批通过后也会流转到保卫处。
- 保卫处补充指派：保卫处发现申请应由部门负责人先审批时，可指定该部门审批人并转回部门审批。
- 二维码查询：申请提交后自动生成专属二维码，访客和门卫可扫码查看审批状态。
- 大屏展示：只展示最终审批通过的访客，支持当前有效、即将到访、已失效、全部已通过筛选；数据每 5 秒刷新，时间每秒刷新。
- 管理端：系统管理员可维护部门、账号和申请记录。
- 账号筛选：账号管理页面支持按角色、所属部门筛选账号。
- 修改密码：所有登录账号均可自行修改密码。
- 学校品牌：页面已加入学校校徽和“河北省科技工程学校”名称。
- 一键启动/停止/部署：提供 Windows 启停脚本，以及 Windows/Linux 部署脚本。

## 技术栈

- Node.js
- Express
- EJS
- MySQL
- pnpm

## 默认数据库配置

系统默认连接本地 MySQL：

```text
地址：localhost
端口：3306
用户名：root
密码：root
数据库：xiaoyuanfangke
```

首次启动会自动创建数据库、数据表、默认部门和默认账号。

正式部署时建议创建专用 MySQL 用户，不建议长期使用 `root/root`。

## 本地运行

1. 确保 MySQL 已启动。

2. 安装依赖：

   ```bash
   pnpm install
   ```

3. 启动系统：

   ```bash
   pnpm start
   ```

4. 浏览器访问：

   ```text
   访客申请：http://localhost:3000/
   后台登录：http://localhost:3000/login
   大屏展示：http://localhost:3000/screen
   健康检查：http://localhost:3000/health
   ```

5. 检查数据库：

   ```bash
   pnpm check:db
   ```

## 角色与权限

### 系统管理员

系统管理员登录后只显示管理类功能：

- 部门管理
- 账号管理
- 申请管理
- 审批查看
- 修改密码
- 退出

### 部门账号

部门账号必须绑定具体部门。

- 可查看本部门全部申请。
- 若账号具有审批权限，可审批本部门“待部门负责人审批”的申请。
- 若账号没有审批权限，只能查看，不能审批。

### 保卫处账号

保卫处账号通常绑定保卫处。

- 可查看全校申请。
- 若账号具有审批权限，可审批“待保卫处审批”的申请。
- 可在必要时指定部门负责人，将申请转回部门审批。

## 访客申请流程

### 不需要部门负责人审批

```text
访客申请提交 -> 待保卫处审批 -> 已通过/已打回
```

### 需要部门负责人审批

```text
访客申请提交 -> 选择该部门审批负责人 -> 待部门负责人审批 -> 待保卫处审批 -> 已通过/已打回
```

当选择“需要，先提交部门负责人审批”时，申请页会继续显示“部门负责人审批人”下拉框。该下拉框只显示所选部门下：

- 已启用；
- 角色为部门账号；
- 具有审批权限；

的账号姓名。

如果没有选择负责人，前端和后端都会阻止提交。

## 一键启动和停止

Windows 下可直接双击：

```text
启动网站.bat
停止网站.bat
```

启动脚本会：

1. 检查 MySQL `localhost:3306`。
2. 如果 MySQL 未运行，尝试启动常见服务名，如 `MySQL80`、`MySQL`、`MariaDB`。
3. 检查依赖。
4. 启动网站。
5. 写入进程文件 `.xiaoyuanfangke.pid`。

停止脚本只停止本项目的网站进程，不会关闭 MySQL，避免影响本机其他项目。

运行日志：

```text
logs/app.out.log
logs/app.err.log
```

## 一键部署

### Windows 服务器

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy-windows.ps1 -SiteUrl "http://服务器IP:3000"
```

### Linux 服务器

```bash
chmod +x deploy-linux.sh
SITE_URL="http://服务器IP:3000" ./deploy-linux.sh
```

如果二维码需要手机扫码访问，请将 `.env` 中的 `BASE_URL` 设置为手机可访问的服务器 IP 或域名，不能使用 `localhost`。
