# 校园访客审批平台部署说明

本文说明如何将校园访客审批平台部署到学校服务器，包含 Windows Server 和 Linux 两种部署方式。

## 1. 系统组成

本系统由三部分组成：

- Web 服务：Node.js + Express
- 数据库：MySQL
- 静态页面与模板：EJS + CSS

默认端口：

- 网站端口：`3000`
- MySQL 端口：`3306`

默认数据库：

- 数据库名：`xiaoyuanfangke`
- 用户名：`root`
- 密码：`root`

正式部署时建议不要继续使用 `root/root`，应创建专用数据库账号。

## 2. 部署前准备

服务器需要安装：

- Node.js 20 或更高版本
- pnpm
- MySQL 8 或 MariaDB 10+
- Git

可选：

- Nginx：Linux 下用于反向代理和 HTTPS
- IIS 或 Nginx for Windows：Windows 下用于反向代理和 HTTPS
- PM2：用于守护 Node.js 服务

## 3. 获取项目代码

在服务器上选择部署目录，例如：

Windows：

```powershell
cd D:\web
git clone https://github.com/hlt1986/xiaoyuanfangke.git
cd xiaoyuanfangke
```

Linux：

```bash
cd /opt
git clone https://github.com/hlt1986/xiaoyuanfangke.git
cd xiaoyuanfangke
```

如果代码不是从 GitHub 获取，也可以直接复制整个项目目录到服务器。

## 4. 配置环境变量

复制示例配置：

Windows：

```powershell
Copy-Item .env.example .env
notepad .env
```

Linux：

```bash
cp .env.example .env
nano .env
```

示例：

```env
PORT=3000
BASE_URL=http://学校服务器IP:3000

DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=root
DB_NAME=xiaoyuanfangke

SESSION_SECRET=请替换成一段随机字符串
```

字段说明：

| 配置 | 说明 |
| --- | --- |
| `PORT` | Node.js 网站监听端口 |
| `BASE_URL` | 二维码中使用的网站根地址 |
| `DB_HOST` | MySQL 地址 |
| `DB_PORT` | MySQL 端口 |
| `DB_USER` | MySQL 用户名 |
| `DB_PASSWORD` | MySQL 密码 |
| `DB_NAME` | 数据库名 |
| `SESSION_SECRET` | 登录会话密钥 |

注意：如果二维码要给手机扫码访问，`BASE_URL` 不能写 `localhost`，必须写手机可以访问的服务器 IP 或域名。

## 5. MySQL 配置

### 5.1 简单方式

确保 MySQL 已启动，并且 `.env` 中配置的账号能创建数据库和表。

首次启动网站时，系统会自动创建：

- 数据库 `xiaoyuanfangke`
- 部门表
- 账号表
- 访客申请表
- 默认部门
- 默认管理员和保卫处账号

### 5.2 推荐正式方式

生产环境建议创建专用账号。

```sql
CREATE DATABASE IF NOT EXISTS xiaoyuanfangke
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

CREATE USER 'visitor_app'@'localhost' IDENTIFIED BY '强密码';
GRANT ALL PRIVILEGES ON xiaoyuanfangke.* TO 'visitor_app'@'localhost';
FLUSH PRIVILEGES;
```

然后修改 `.env`：

```env
DB_USER=visitor_app
DB_PASSWORD=强密码
```

## 8. Windows Server 部署

### 8.1 使用一键脚本启动

项目内置：

- `启动网站.bat`
- `停止网站.bat`

双击 `启动网站.bat` 即可启动网站。脚本会：

1. 检查 MySQL 是否监听 `localhost:3306`。
2. 如果未监听，尝试启动常见 MySQL 服务名。
3. 检查依赖。
4. 启动网站。
5. 将进程 ID 写入 `.xiaoyuanfangke.pid`。

双击 `停止网站.bat` 可停止本项目网站进程。

### 8.2 使用 PM2 守护进程

安装 PM2：

```powershell
npm install -g pm2
```

启动：

```powershell
pm2 start src/server.js --name xiaoyuanfangke
pm2 save
```

查看：

```powershell
pm2 status
pm2 logs xiaoyuanfangke
```

停止：

```powershell
pm2 stop xiaoyuanfangke
```

### 8.3 设置开机自启

Windows 可使用“任务计划程序”：

1. 打开任务计划程序。
2. 创建基本任务。
3. 触发器选择“计算机启动时”。
4. 操作选择“启动程序”。
5. 程序选择项目中的 `启动网站.bat`。
6. 设置“使用最高权限运行”。

## 9. Linux 部署

### 9.1 使用 PM2

安装 PM2：

```bash
npm install -g pm2
```

启动：

```bash
pm2 start src/server.js --name xiaoyuanfangke
pm2 save
pm2 startup
```

按 `pm2 startup` 输出的命令继续执行，即可配置开机自启。

常用命令：

```bash
pm2 status
pm2 logs xiaoyuanfangke
pm2 restart xiaoyuanfangke
pm2 stop xiaoyuanfangke
```

### 9.2 使用 systemd

创建服务文件：

```bash
sudo nano /etc/systemd/system/xiaoyuanfangke.service
```

内容示例：

```ini
[Unit]
Description=Xiaoyuan Fangke Visitor Approval System
After=network.target mysql.service

[Service]
Type=simple
WorkingDirectory=/opt/xiaoyuanfangke
ExecStart=/usr/bin/node /opt/xiaoyuanfangke/src/server.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```

启用：

```bash
sudo systemctl daemon-reload
sudo systemctl enable xiaoyuanfangke
sudo systemctl start xiaoyuanfangke
sudo systemctl status xiaoyuanfangke
```

查看日志：

```bash
journalctl -u xiaoyuanfangke -f
```

## 10. Nginx 反向代理

如果希望使用域名或 80/443 端口，可配置 Nginx。

示例：

```nginx
server {
    listen 80;
    server_name visitor.example.edu.cn;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

检查并重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

如果使用域名，`.env` 中的 `BASE_URL` 应改为：

```env
BASE_URL=http://visitor.example.edu.cn
```

启用 HTTPS 后应改为：

```env
BASE_URL=https://visitor.example.edu.cn
```

## 11. 防火墙放行

### Windows

如果直接访问 3000 端口，需要在 Windows 防火墙中放行 TCP 3000。

PowerShell 管理员执行：

```powershell
New-NetFirewallRule -DisplayName "xiaoyuanfangke-3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
```

如果使用 IIS/Nginx 代理到 80/443，则放行 80/443。

### Linux

Ubuntu UFW：

```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
```

如果直接暴露 3000：

```bash
sudo ufw allow 3000/tcp
```
